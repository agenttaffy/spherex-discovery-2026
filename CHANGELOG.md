## [1.4.6] - 2026-11-14
### Fixed & Hardened — Spectrum & Temperature Fit Scientific Truthfulness Pass
- **Neutral Broadband Continuum Shape Descriptions:** In `spectrum.py`, replaced all inferred broad-band astrophysical classifications ("Cold Sub-stellar / Brown Dwarf Candidate Profile", "Cool Stellar Atmosphere Candidate Profile", "Candidate Circumstellar Dust / Disk Profile") with neutral measured-shape descriptions only ("flux rises toward longer measured bands", "flux falls toward longer measured bands", "peak among measured detector bands", "insufficient observed coverage"). Added `continuum_shape` field to summary and API responses, while retaining `spectral_class` for backward compatibility, mapped to the same neutral description. Updated UI chart and exported discovery report to clearly document that this is a broadband continuum shape, not an astrophysical classification.
- **Strict Temperature Fit Constraints (Minimum 3 Bands & Propagated Errors Required):** In `spectrum.py` (`fit_blackbody_continuum`), tightened fitting requirements: a two-parameter (amplitude + temperature) fit requires at least 3 distinct measured detector bands with valid propagated photometric errors to guarantee positive residual degrees of freedom ($\text{dof} \ge 1$). Removed unsupported 10% flux error substitution when errors are absent. If degrees of freedom $< 1$, or any input lacks valid propagated error, or fit identifiability/curvature is unconstrained, returns `status: "unavailable"` and no temperature. Labeled retained fit as single-temperature blackbody continuum fit; exposed actual inputs, uncertainties, dof, reduced $\chi^2$, and explicit limitations.
- **Zero-Observation Summary Metrics Unavailable:** In `spectrum.py` (`generate_spectrum_for_target`), when zero observed archive bands exist, `peak_wavelength_um`, `peak_detector`, `peak_flux_mjy_sr`, `estimated_temperature_k`, and `integrated_flux_mjy_sr_um` are set to `None` (`unavailable`), with `peak_is_measured: False`. Synthetic continuum curves and placeholder fluxes (0.05) are never described as observed channels/resolution and are never reported as measured peaks.
- **Frontend & Discovery Report Clarity:** In `SpectrumChart.tsx`, updated summary bar to display "Continuum Shape:" and italic caption "Broadband continuum shape only; not an astrophysical classification." Gracefully handles unavailable peak wavelength/detector (`Unavailable`). In `report.py` (`generate_discovery_report`), SED section reports broadband continuum shape and documented fit with clear caveat that it is a single-temperature broadband fit, not an object's known physical temperature.
- **Regression Suite:** Added focused regression tests in `test_scientific_audit_regression.py` covering two-band no-fit, missing-error no-fit, three-band documented fit, neutral profile output, and no-observation summary metrics. Backend suite passing **93 tests** (0 failures).

## [1.4.5] - 2026-11-14
### Fixed & Hardened — Scientific Truthfulness Review & Robustness Pass
- **Astrometric Motion Target Tracking Without Blind Substitution:** In `motion.py` (`measure_astrometric_motion`), ensured that when a celestial target is requested (`target_coord`), failed WCS projection or undetectable target centroids strictly return `centroid_detected: False` with zero motion instead of silently substituting the blind brightest peak in the frame. Removed dead unreachable code after return in `_find_local_centroid`.
- **Quality Flags Metadata Truthfulness & Elimination of Hardcoded Bit Guesses:** In `fits_processing.py` (`evaluate_quality_flags`), added `allow_legacy_synthetic=False` parameter. Preserves an explicit unknown/missing state (`quality_state: "unknown_metadata_missing"`) when FITS headers lack `MSKN`/`MSKM` cards rather than guessing flag semantics from undocumented bits. Removed hardcoded fallback integers in mask planes.
- **3D Celestial WCS Support & Cutout Boundary Protection in Dispersion Extraction:** In `fits_processing.py` (`extract_calibrated_wavelength`), extracted 2D sub-WCS via `w.celestial` for multi-axis spectral cubes (`NAXIS=3`), and verified target coordinates lie within cutout boundaries (`[0, NAXIS1)`, `[0, NAXIS2)`) before evaluating 2D dispersion calibration tables, returning `None` (`unavailable`) for targets outside the frame.
- **Planck Blackbody Continuum Robustness & Classification Metadata:** In `spectrum.py` (`fit_blackbody_continuum`), guarded against `TypeError` when input flux errors are `None` or non-positive. Enforced a minimum of 2 distinct observed wavelengths/bands (returning `status: "unavailable"` for zero spectral baseline). Set `degrees_of_freedom = 0` and `reduced_chi2 = None` for 2-point fits. Added documented `continuum_classification` reporting profile method, inputs, and limitations.
- **Default NaN Preservation in FITS Image Extraction:** In `fits_processing.py` (`extract_primary_image`), set `preserve_nan: bool = True` as default across all scientific analysis pipelines, preserving non-finite pixels as masks while providing `preserve_nan=False` for display backwards compatibility.
- **Coadd Stack RuntimeWarning Cleanliness:** In `stacking.py` (`compute_coadd_stack`), wrapped `np.nanmean` with a targeted RuntimeWarning filter for all-NaN empty slices. In `ComparisonView.tsx`, prevented negative gain percentages from rendering as `+-20%`. Exposed `snr_gain_status` and `theoretical_gain_model` via `/science/stack`.
- **Regression Suite:** Added new regression test `test_audit_motion_requested_target_never_substitutes_brightest_peak`. Backend suite passing **92 tests** (0 failures).

## [1.4.4] - 2026-11-14
### Fixed & Hardened — Scientific Truthfulness Pass & Uncensored Estimators
- **Explicit Unavailable State in Photometry:** In `photometry.py` (`compute_aperture_photometry`), eliminated silent fallback to the image center when `target_coord` fails WCS projection or returns non-finite coordinates. Photometry now returns explicit `status: "unavailable"`, `valid: False`, with descriptive `reason`, and never substitutes the image center or brightest peak. Wired into `build_lightcurve_series` so lightcurve summaries exclude unavailable epochs from flux statistics.
- **WCS-WAVE Celestial Projection & Missing Mask Metadata State:** In `fits_processing.py` (`extract_calibrated_wavelength`), removed fallback to image center when `target_coord` was supplied but could not be projected via celestial WCS; center dispersion is only measured when caller explicitly passes `target_coord=None`. In `extract_fatal_quality_mask`, preserved an explicit unknown/missing quality state (`None`) when mask metadata (`MSKN*`/`MSKM*` cards) are absent, eliminating undocumented bit inference from real SPHEREx data while confining legacy bit checking strictly to explicit test fixtures (`allow_legacy_synthetic=True`).
- **Elimination of Target Preset Claims & Documented SED Fit:** In `spectrum.py`, removed all preset-name/coordinate matching (Barnard's Star, WISE 0855, RW Aurigae, R Draconis, Epsilon Indi B) and hardcoded default temperatures (260K, 3150K, 4200K, 2800K, 1300K). Implemented `fit_blackbody_continuum` returning documented single-temperature Planck blackbody fits with temperature, uncertainty, reduced $\chi^2$, degrees of freedom, inputs, and limitations when $\ge 2$ observed bands exist, or `None` when $< 2$ bands exist. Explicitly labeled 102 channels as an illustrative estimated continuum, never observed resolution.
- **Uncensored Empirical SNR Improvement Estimator:** In `stacking.py` (`compute_coadd_stack`), eliminated arbitrary clamping of `snr_improvement_factor` to `[0.5, 2.5 * sqrt(N)]`. Reports actual measured empirical estimator (e.g. 1.0 for identical frames) or `None` with `snr_gain_status: "unavailable"` when assumptions/samples do not support a value, keeping theoretical $\sqrt{N}$ distinct.
- **NaN/Inf Preservation as Masks:** Removed fabricated fill values (`min_finite`, `bg_fill`, `bg_median`) from FITS image extraction, aperture photometry, image stacking, and centroiding. Invalid pixels remain masked as NaN across scientific analysis pipelines.
- **Regression Suite:** Added 5 new regression tests in `test_scientific_audit_regression.py` covering all 5 audit issues. Full backend suite passes: **91 tests** in 7.98s; accessibility suite: **41 checks**; clean production build.
### Fixed & Hardened — Astrometric Pointing Registration Isolation & Lightcurve Source Masking
- **Pointing Registration Isolation in Astrometric Motion:** In `motion.py`, projected epoch 2 celestial position `sky2` back into epoch 1 reference frame WCS grid (`w_obj1.world_to_pixel(sky2)`). This ensures target displacement (`dx_pixels`, `dy_pixels`) reflects true physical celestial motion on the sky, completely preventing telescope pointing registration offsets between epochs from being falsely classified as target proper motion (`Stationary / Sub-threshold` preserved). Centroids in diff overlays are registered to the difference frame coordinates. Added `frame_registration_shift_pixels` telemetry.
- **Source Mask Background Exclusion in Multi-Epoch Light Curves:** In `photometry.py` (`build_lightcurve_series`) and `science.py` (`/science/photometry`), extracted `source_mask` and wired it into epoch frames so neighboring field stars are excluded from the background annulus across multi-epoch light curves without rejecting target aperture flux.
- **Discovery Report Astrometric Provenance:** In `report.py`, added equatorial vector proper motion components ($\mu_\alpha \cos\delta$, $\mu_\delta$) and WCS-anchored centroiding calibration provenance.
- **Regression Suite Expansion:** Added `test_priority_3_pointing_shift_not_presented_as_target_motion` and `test_priority_1_lightcurve_source_mask_background_exclusion` to `test_scientific_audit_regression.py`. Total verified tests: **86 backend pytest tests** (0 failures), **41 accessibility checks** (0 failures), and clean production build. Reconciled all documentation records.
